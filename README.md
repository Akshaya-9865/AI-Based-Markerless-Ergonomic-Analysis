# Car Seating Comfort Motion Analysis System

A full-stack **markerless biomechanical motion analysis platform** for evaluating seated posture, joint kinematics, motion smoothness, and comfort using a single RGB camera. The system integrates **React.js** for the frontend, **FastAPI** for the backend, and **MediaPipe Pose** for markerless human pose estimation, providing automated analysis, annotated videos, graphical reports, and downloadable research datasets.

## 📖 Overview

The Car Seating Comfort Motion Analysis System is designed to provide an accessible alternative to laboratory-based motion capture systems for seated ergonomic assessment. Using a single sagittal-view RGB video, the application estimates body landmarks, computes joint angles, analyzes motion characteristics, and generates research-grade outputs suitable for ergonomic studies and biomedical engineering applications.
